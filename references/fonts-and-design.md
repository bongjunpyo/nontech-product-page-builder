# Fonts and Design Reference

## Web Fonts by Language

Always use free Google Fonts. Include fallback fonts to prevent broken text.

| Language | Font | Import |
|---|---|---|
| Korean | Noto Sans KR | `@import url('https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;500;700&display=swap')` |
| English | Inter | `@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;700&display=swap')` |
| Japanese | Noto Sans JP | `@import url('https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400;500;700&display=swap')` |
| Simplified Chinese | Noto Sans SC | `@import url('https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;700&display=swap')` |

| Vietnamese | Noto Sans | `@import url('https://fonts.googleapis.com/css2?family=Noto+Sans:wght@400;500;700&display=swap')` |
| Thai | Noto Sans Thai | `@import url('https://fonts.googleapis.com/css2?family=Noto+Sans+Thai:wght@400;500;700&display=swap')` |

## Website Analysis Criteria

When fetching the company website, look for:

- **Main colors** — primary, secondary, accent colors used
- **Spacing** — tight and dense, or spacious and airy?
- **Button style** — rounded, sharp, outlined, filled, ghost?
- **Image usage** — large hero photos, product-only, lifestyle, or minimal?
- **Writing tone** — formal, friendly, technical, emotional, minimal?
- **Layout** — single column, grid, asymmetric, centered?
- **Premium feeling** — does it feel luxury or accessible?
- **Friendliness** — does it feel approachable or authoritative?
- **Technical feeling** — does it feel high-tech or everyday?
- **Practicality** — does it emphasize utility or experience?

Summarize this as the "brand atmosphere" to show the user before generating HTML.

## Alternative Style Directions

Offer these only if the user says they want something different from the current website.

### Apple-inspired
- Minimal layout
- Large, full-width product images
- Short, punchy copy
- Wide spacing — sections breathe
- Clean sans-serif typography
- Neutral or monochrome palette with one accent

### Startup SaaS-inspired
- Problem → Solution narrative structure
- Card-based feature sections
- Strong calls to action ("Buy Now", "Get Started")
- Icon + headline + short description pattern
- High contrast — light background, bold text

### Premium Brand-inspired
- Refined, calm section flow
- Emotional, story-driven copy
- Subtle color palette
- Generous whitespace
- Typography-forward design

**Important:** Do not copy the design, copy, or visual elements of any specific brand. Use only the general feel and structure as inspiration.
